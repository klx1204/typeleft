## Failure paths

| Case | Behaviour |
| --- | --- |
| Pandoc missing | Dialog header and engine tab show “Pandoc not found”; export reports `pandoc-not-found` with a Settings hint. |
| PDF engine missing/invalid | `engine-not-found:<name>` / `engine-path-invalid:<path>`; export stops without writing a partial file. |
| Missing local images | Preflight lists them and asks for confirmation; the list is repeated after export. |
| Failed diagram | Diagram is left as code, warning listed as `Diagram warnings`; PlantUML notes the server requirement. |
| User cancel | Process killed; status “Canceled”; no success message. |
| Empty document | Export refuses with “Nothing to export.” |

## Known limitations

- Browser/system printing cannot render CSS margin boxes or `target-counter`
  TOC page numbers; use Paged preview or a PDF engine for running headers and
  TOC page numbers.
- CSS page numbering starts at 1 (WeasyPrint/Paged.js); the start page applies
  to LaTeX engines.
- Footnotes follow Pandoc; the browser path keeps references inline.
- CJK detection is a font stack, not font-file inspection.
- PlantUML rendering depends on the public server; no offline renderer is
  bundled.
