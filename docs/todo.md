# Typeleft 待办（v0.6.0 之后）

按优先级排列；每项都注明验证方式，方便直接接手。

## P1 — 质量与边界

| # | 事项 | 现状 / 验证方式 |
|---|---|---|
| 1 | 剪贴板 Rust 路径真机验证 | 目前只在浏览器 stub 中验证了 HTML 复制/粘贴；需在真实应用里复制到 Word/浏览器再粘回 |
| 2 | Vega / Vega-Lite 渲染自动化 | mermaid 有断言，vega 只验证了代码路径；可在 headless 里断言 `svg` 或 `.vega-embed` 存在 |
| 3 | 图片交互 | 悬停工具条、拖拽缩放手感未测；块级 `<img>` 的 `<figure>`、`style` 组合未规范化 |
| 4 | 光标反向映射（CM6 → Milkdown） | 正向列号已精确；反向仍按行恢复，列不精确 |
| 5 | 搜索范围 | 只在单个 textblock 内匹配，跨段落不支持（文档化即可） |
| 6 | 表格列宽呈现 | 宽度存为 `<!-- tl-cw: … -->`，源码模式可见；可改为隐藏节点或 HTML 表格 |
| 7 | 中文 IME 回归 | 小鹤双拼已人工验证一次，未纳入自动化（可用 CDP + 真实输入法输入事件） |

## P2 — 工程洁净度

| # | 事项 | 说明 |
|---|---|---|
| 8 | 浏览器回归统一输入方式 | 套件仍用 `execCommand`；输入规则已单独用 CDP 验证，可统一为 CDP |
| 9 | 应用外壳测试 | Editor 的源码/富文本切换、大文档横幅、菜单接线没有自动化测试，只有组件级 + 单测 |
| 10 | 依赖巡检 | Milkdown 7.23 / ProseMirror / Tauri 2 的小版本升级与安全更新 |
| 11 | 导出/导入管线 | `src/services/markdown/` 仍是 Muya 时代的 marked 分支与 turndown 规则；可评估迁移到 npm `marked` + 现成 GFM 插件 |
| 12 | CI 覆盖构建 | Test workflow 只跑测试；可加一个 `cargo check` job 提前发现 Rust 编译问题 |

## 已确认不做

- 表格列宽用纯 GFM 表达（语法不支持）
- 大文档所见即所得（ProseMirror 无虚拟化，保持源码模式）
- 协同编辑、移动端
