# Print samples

Generated by `bun run test:print` on macOS 2026-11-22 (headless Chrome).

- `typeleft-print-sample.html` — cover, linked TOC, CJK body text, a table with
  48 rows, code block, heading numbering, running footer `{page}`.
- `typeleft-print-sample.pdf` — 6 pages, A4, Chinese official margins
  (25.4 / 31.8 mm).

The same script runs in the `print` CI job on Ubuntu, macOS and Windows, so
each platform produces its own PDF and asserts page objects and file size.
Pandoc/XeLaTeX/Tectonic/WeasyPrint are detected separately by the app; the
sample intentionally needs no TeX engine.
