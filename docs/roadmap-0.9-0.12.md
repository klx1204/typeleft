# Typeleft 0.9–0.12 开发计划

> **English summary** — Typeleft 0.9–0.12 close the remaining planned gaps
> against Typora: a token-based theme/settings system, TOC and GitHub Alerts,
> Mermaid 11, LaTeX delimiters, file links, emoji shortcodes, strict mode,
> folder search/Open Quickly, file-tree improvements, image file operations,
> draft recovery, custom shortcuts, update notifications, and a complete
> print/PDF subsystem. 1.0 and 1.0-rc are intentionally not scheduled yet.
> Scope, acceptance criteria, testing gates, and non-goals are below.

- 基线：v0.8.0
- 目标版本：0.9 / 0.10 / 0.11 / 0.12
- 1.0 与 1.0-rc：**暂不安排**，0.12 发布后再评估
- 工作量按“单人、熟悉代码库”估算，仅用于排期，不是承诺

> **进度**：0.9、0.10、0.11 已完成（2026-11-22）。

## 3. WP1 主题系统（0.9）

### 3.1 令牌契约

```css
--tl-body-font
--tl-code-font
--tl-editor-bg
--tl-line-height
--tl-paragraph-gap
--tl-list-marker
--tl-focus-dim
```

```html
<div id="write"
     data-direction="ltr|rtl"
     data-heading-numbering="true|false">
```

### 3.2 三态设置

每项支持：

- 跟随主题（默认，不输出覆盖）
- 内置默认
- 自定义

设置面板显示来源，支持“恢复跟随主题”。

### 3.3 导出策略

| 导出 | 策略 |
|---|---|
| HTML / 打印 | C：完整主题 CSS + 资源 + 令牌覆盖 |
| Pandoc（docx/ePub/PDF 等） | B：只应用可映射的令牌，不声称支持完整 CSS 主题 |

### 3.4 任务

| 任务 | 产出 |
|---|---|
| 重构 `layoutCss` | 去 `!important`，令牌 + 属性；只对显式覆盖生成 CSS |
| 设置模型/UI | 8 个外观项三态、来源标识、重置、预览 |
| HTML/打印导出 | 包 `#write/.ProseMirror`，内联主题 CSS + 资源 + 令牌 |
| 主题调试面板 | 令牌值/来源、主题文件、重新加载、打开目录、被拦截资源 |
| 双语作者文档 | 英文 + 中文；README 互链；设置页入口；旧兼容文档标注历史 |
| 测试 | theme 模式断言三态/属性/导出；文档链接检查 |

**验收**

- 不修改设置时主题完全保持原样；
- 显式覆盖在编辑器与 HTML/打印导出中一致；
- Pandoc 文档明确说明不继承 CSS 主题；
- 第三方主题仍可只写 CSS 生效。

## 9. WP7 完整打印 / PDF（0.12）

### 9.1 页面

- 纸张：A3 / A4 / A5 / B5 / Letter / 自定义（宽×高 mm）
- 方向：纵向 / 横向
- 页边距：常规、**中文公文（上下 2.54 / 左右 3.18）**、窄、适中、宽、自定义
- 默认：A4 + 中文公文边距

### 9.2 排版

- 正文字体、字号、行高
- 标题字体/字号层级
- 代码字体、代码高亮主题
- 中文字体自动探测 + 手动指定
- 段距、首行缩进、两端对齐
- 标题编号与编辑器一致

### 9.3 结构

- 封面页：标题、副标题、作者、日期（可开关）
- 目录：深度、标题、是否带页码
- 每章新页、标题与正文不分离、孤行/寡行控制
- 表格跨页重复表头
- 图片最大宽度/DPI/对齐
- 脚注位置

### 9.4 页眉页脚与元数据

- 页眉/页脚左/中/右三个区域
- 奇数页/偶数页不同、首页不同
- `{page}`、`{total}`、`{title}`、`{author}`、`{date}`
- 页码格式与起始页
- PDF 标题/作者/主题/关键词

### 9.5 内容

- 数学公式
- **图表预渲染**：Mermaid / flowchart / sequence / PlantUML / Vega → SVG/PNG
- 代码高亮、内部锚点/外链、PDF 书签/大纲
- 图片缺失、图表失败、字体缺失的明确提示
- 分页标记、TOC、Alerts、Emoji

### 9.6 路径与引擎

| 路径 | 能力 |
|---|---|
| 系统打印 | 打印专用 HTML + `@page`；纸张/边距/分页可控；页眉页脚受系统限制，UI 明示 |
| Pandoc + XeLaTeX/Tectonic | 页面、封面、目录、编号、页眉页脚、字体、CJK、代码、书签、元数据完整 |
| Pandoc + WeasyPrint | CSS paged media；纸张/边距/页码/页眉页脚 |
| 引擎管理 | 检测版本、指定路径、缺失提示、错误日志；不自动安装 |

### 9.7 交互

- 打印预览
- 导出进度/取消
- 导出后打开文件/文件夹
- 打印预设
- 每文档 front matter 覆盖
- 当前引擎能力矩阵

### 9.8 验收

- 中英文样例：长文、表格、代码、图片、公式、图表、脚注、Alerts、TOC
- 四平台实际打印/PDF 验证
- 引擎/字体/图片缺失的失败路径
- 页数、页眉页脚、目录、书签检查

**预估**：15–20 天；加稳定化 5–8 天。

## 10. 测试与发布门槛

每个版本必须通过：

1. `bun run test:engine`
2. `bun run test:roundtrip`（全部 fixture 幂等）
3. `bun run test:cm6`
4. `bun run test:search`
5. `bun run test:web`（新增模式）
6. `cargo test --lib`
7. `cargo tauri build`
8. 四平台 CI（macOS universal / Windows / Linux x64 / Linux arm64）
9. 隐私扫描：无个人路径/邮箱/手机号
10. 许可证扫描：NOTICE 覆盖 bundled 代码与资源

新增测试方向：

- 主题：令牌、三态、HTML/打印导出、第三方主题兼容
- A 块：TOC/Alerts/LaTeX/Emoji/文件链接的 roundtrip 与渲染
- 搜索：无索引流式扫描、取消、上限、结果跳转
- 文件：拖拽移动、撤销、监听（临时目录）
- 图片：下载/移动/复制/删除失败路径
- 打印：四平台样例、页数/页眉页脚/目录/书签

## 11. 风险与应对

| 风险 | 应对 |
|---|---|
| Mermaid 11 API 破坏性变化 | 先做 POC；旧图回归夹具 |
| HTML/打印主题导出复杂 | 先包 `#write` + 内联主题；逐步补资源清洗 |
| 跨文件搜索在老机器/HDD 慢 | 上限、取消、进度；只搜当前目录选项 |
| 监听在 Linux/网络盘失效 | 按需 watch + 轮询回退 |
| 图片批量操作误删 | 预览、回收站、撤销、默认不覆盖 |
| PDF 中文缺字 | 自动探测 CJK 字体 + 手动指定 |
| 打印三路径能力不一致 | UI 显示能力矩阵，失败给明确指引 |
| 快捷键冲突 | 录制时检测；保留重置 |
| GPL 合规 | WP0 先完成 NOTICE、字体/emoji 替换再发版 |

## 12. 完成后的 Typora 差距
