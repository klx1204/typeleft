## WP3 — search and navigation

| Item | Evidence |
| --- | --- |
| Cross-file search (no index) | Rust `search_folder` streams the tree with the `ignore` crate (`.gitignore`), skips binary files and files > 5 MB, caps at 1000 hits; the FolderSearch modal debounces queries and supports case/regex/whole-word settings. |
| Quick Open | `list_folder_files` enumerates in-memory names; the Files tab fuzzy-matches and opens a result. |
| Tag search | Rust parser reads YAML/TOML front matter tags; the Tags tab filters and opens a file. |
| Filename fuzzy search | Same Files tab, reused by the Sidebar filter. |
| Outline collapse/flat | Sidebar TOC has per-item collapse, hidden descendants and a flat mode. |
| File tree keyboard navigation | Up/Down move focus, Right expands, Left collapses, Enter opens. |

No persistent index is created. Memory/disk behaviour is documented in the
roadmap: only a session filename list and tag results.

Browser evidence: `foldersearch` asserts a content hit appears and clicking it
emits `LoadFile`; `filelist` asserts list view and name filtering.

## WP4 — file tree and external changes

| Item | Evidence |
| --- | --- |
| List view | Header toggle loads `list_folder_files` and renders a flat sorted list. |
| Sidebar filter | Name filter applied to both tree and list. |
| Sort/group | Name / modified / type, folders first; choice persisted in localStorage. |
| Drag to move | File/folder items are draggable; dropping on a folder calls `move_file`, checks collisions, updates `FileRenamed` and refreshes. |
| Undo file operations | Rename/move are replayed backwards; delete first copies the item to `app_data/undo` and restores from it. The backup directory removes entries older than 7 days. |
| External watcher | `notify` watches the open folder plus expanded subfolders (non-recursive per path), debounces events and refreshes the tree. |

Rust tests: front matter tag parsing and copy/restore of an undo backup.

## Known limitations

- Cross-file search is read-only; replace is not implemented.
- No persistent index; very large folders may take a few seconds on first query.
- Watcher paths are non-recursive; only the open folder and expanded directories
  are watched. Network drives may require polling fallback.
- Undo history is session-only; delete backups are kept for 7 days at most.
- Quick Open/tag search only index names/tags, not file contents.
