## HTML compatibility

- HTML blocks and inline HTML render through DOMPurify; raw source is stored on
  the node and serialized unchanged (`roundtrip-html.md` identical + idempotent).
- Inline tag pairs are merged so `<span style>` keeps styling; media-only
  paragraphs become block nodes.
- `<u>`/`<ins>` become an editable underline mark.
- `<video>`/`<audio>` render with controls; `<iframe>` is limited to http(s) and
  sandboxed.
- Media paths honour the document folder and `typora-root-url`; dropped
  image/video/audio files insert the matching node.
- Browser assertions: HTML block text, red inline span, underline, video,
  sandboxed iframe, and a dropped video block.

## Tables

- Drag handles for the current row and column, a 2px drop indicator, and
  `prosemirror-tables` move commands.
- Alt+Arrow keys and toolbar buttons provide the accessible path.
- CDP: handles appear, Alt+Down moves a row, dragging a column shows the
  indicator and reorders the header.
- Moving cells carries `colwidth`, so the `tl-cw` comment follows the new order.

## Import / export

- Pandoc detection (custom path, PATH, Homebrew locations) with version.
- Export formats: PDF, docx, odt, epub, latex, rst, rtf, opml, Reveal.js,
  Markdown (GFM/CommonMark) and plain text.
- PDF falls back to the print dialog when Pandoc or a PDF engine is missing.
- Import docx/odt/epub/rst with `--extract-media`; HTML import already existed.
- Custom export command with `{input}`, `{output}`, `{title}`.
- Unit tests build arguments and split quoted commands; fake Pandoc scripts
  verify that export writes the requested file and import returns Markdown.
- Browser export dialog checks: configs listed, format list, Pandoc warning,
  reorder persisted.
