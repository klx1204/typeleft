# v0.7.0 verification record

Snapshot of how the 24 small items from
`docs/typora-vs-typeleft-v0.6.md` were checked. Automated evidence is listed
first; where a menu or native window is involved the manual step is written
down as well.

## Commands

| Command | Result |
| --- | --- |
| `bun run test:engine` | PASS (engine + front-matter export + search URL cases) |
| `bun run test:roundtrip` | PASS, 5/5 fixtures idempotent |
| `bun run test:cm6` | PASS |
| `bun run test:search` | PASS |
| `bun run test:web` | PASS, 10 modes (default / theme / layout / codeblock / sidebar / folders / export / settings / searchmenu / pickers) |
| `bun run test:rust` | PASS, 5 CLI parsing tests |
| `cargo tauri build --bundles app` | PASS, `Typeleft.app` bundled |
| Release workflow `v0.7.0` | PASS, 4 platforms, 10 assets |

CDP scripts (headless Chrome + real key events) were used for the typing
behaviour that synthetic events cannot exercise: auto-pairing, markdown input
rules, `superSubScript`, fence indentation, default language, zoom, and the
selection search menu.
