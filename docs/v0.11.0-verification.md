## WP5 — images

| Item | Evidence |
| --- | --- |
| #117 download remote images | Image Manager lists Markdown/HTML image refs, downloads remote ones with `download_image` (ureq), names by detectable type, and rewrites both Markdown and HTML sources. Failures are collected in the panel. |
| #118 move/copy all | `move_image_to_dir` / `copy_image_to_dir` flatten into the target directory and call `ensure_unique_path`, so existing files are never overwritten. References are rewritten after each success. |

`replaceImageSrc`, `removeFirstImageRef`, `localImagePath`,
`imageMarkdownSrc`) and are covered by engine tests.

remote ref to the saved local path, Delete removes the local ref and records the
file deletion.

## WP6 — drafts, shortcuts, updates

| Item | Evidence |
| --- | --- |
| #19 draft recovery | `save_draft`/`load_draft`/`clear_draft` store `drafts/latest.json`; the editor snapshots every 1.5 s when content differs from the saved file and offers the draft at startup. `shouldOfferDraft` rejects empty, identical, future-dated and >7-day-old drafts. Successful saves clear the draft. |
| #163 custom shortcuts | Settings → Shortcuts records key combinations per action (menu/command palette only), stores `customShortcuts`, and calls `apply_shortcuts`, which rewrites native menu accelerators (falling back to built-in defaults when a value is removed). |
| #167 update check | Help → Check for Updates (and startup option) calls GitHub `releases/latest` — pre-releases are excluded — compares semver, and only offers a button that opens the release page. No automatic download or install. |

Browser evidence (`shortcuts`): the Shortcuts section renders and recording
`Ctrl+Alt+Shift+K` saves `CmdOrCtrl+Alt+Shift+K` for `save`.

Engine evidence: `draft is offered only when recent and different`, `shortcuts
build accelerators from events`.

## Known limitations

- Image Manager uses native folder dialogs and confirm/prompt dialogs; there is
  no drag-and-drop into the manager table.
- Batch operations are sequential per image (predictable progress, no partial
  overwrite).
- Drafts keep a single most-recent buffer, not per-file/per-window history.
- Custom accelerators are validated by the platform; invalid combinations are
  ignored by the native menu.
- Update checks need network access and only cover stable GitHub releases; no
  in-app installer or signature check.
